🧱 Módulo 1 (1/3) • Introdução aos Conceitos

Conhecendo: .title, ft.Text, page.add() e ft.run()

Antes de ver o código completo, entenda o papel exato de cada um dos 4 comandos que criam uma janela visual!

1. page.title = "..." title = título da janela

Muda o nome que aparece na barra superior da janela do programa. Recebe um texto entre aspas.

page.title = "Meu App" # Nome no topo da janela
2. ft.Text("...", size, color, weight) Text = texto visual na tela

Cria um texto visual (substitui o print). Podemos escolher tamanho (size), cor (color) e espessura negrito (weight="bold").

aviso = ft.Text("Olá!", size=24, color="cyan", weight="bold")
3. page.add(item1, item2) add = adicionar na tela

Fixa os elementos dentro da janela. Se você criar um ft.Text mas não passá-lo no page.add(), ele não aparece!

page.add(aviso) # Coloca a variável aviso na janela
4. ft.run(main) run = rodar / ligar o app

Vai sempre na última linha do arquivo. Ele manda o Flet abrir a janela construída dentro da função def main(page: ft.Page):.

ft.run(main) # Abre a janela do aplicativo

🖱️ Módulo 2 (1/3) • Introdução aos Conceitos

Interação: ft.TextField, ft.Button, on_click e page.update()

Agora vamos permitir que o usuário digite informações, clique em botões e veja a tela responder na hora!

1. ft.TextField(label="...") TextField = campo de digitar

Cria uma caixa de digitação na janela. O que o usuário digitar fica guardado dentro de nome_do_campo.value.

caixa_nome = ft.TextField(label="Digite seu nome") # Para ler o que foi digitado: caixa_nome.value
2. ft.Button("Texto", on_click=acao) Button = botão | on_click = ao clicar

Cria um botão clicável. O parâmetro on_click aponta para o nome da função (sem parênteses!) que vai rodar no clique.

botao = ft.Button("Confirmar", on_click=responder)
3. def responder(e): + .value e = evento do clique | value = valor

A função ligada ao botão recebe (e) e pode mudar o texto de qualquer ft.Text alterando o seu .value.

def responder(e): mensagem.value = f"Olá, {caixa_nome.value}!"
4. page.update() update = atualizar a tela

Obrigatório no final da função do botão! Avisa ao Flet: "Mudei dados no código, redesenhe a tela agora!"

page.update() # Faz o novo texto aparecer na hora!

📐 Módulo 3 (1/3) • Introdução aos Conceitos

Organizando a Tela: ft.Column, ft.Row e Alinhamentos

Entenda como empilhar elementos na vertical (Column), alinhar lado a lado (Row) e centralizar sem confusão!

1. ft.Column([item1, item2], spacing=15) Column = coluna vertical ⬇️

Recebe uma lista [ ] de componentes e os empilha de cima para baixo. O spacing define o espaço em pixels entre eles.

coluna = ft.Column([titulo, campo], spacing=15)
2. ft.Row([btn1, btn2], spacing=10) Row = linha horizontal ➡️

Recebe uma lista [ ] de componentes e os coloca lado a lado na mesma linha horizontal. Perfeito para barras de botões!

linha_botoes = ft.Row([botao_criar, botao_limpar], spacing=10)
3. ft.MainAxisAlignment.CENTER MainAxis = eixo principal da fila

Usado no parâmetro alignment=... de uma ft.Row para centralizar os botões lado a lado no meio da linha (ou .SPACE_BETWEEN para separar nas pontas).

# Dentro de ft.Row([...], alignment=ft.MainAxisAlignment.CENTER)
4. ft.CrossAxisAlignment.CENTER CrossAxis = eixo cruzado (lateral)

Como a Column desce na vertical, seu eixo cruzado é a horizontal! Usamos em horizontal_alignment=... para centralizar a coluna no meio da janela.

# Em ft.Column([...], horizontal_alignment=ft.CrossAxisAlignment.CENTER)

Comparando 3 ft.Row com Alinhamentos Diferentes na Mesma Tela

Copie e rode este placar interativo para ver a diferença visual entre START, CENTER e SPACE_BETWEEN!

🐍 exemplo_03_repeticao.py ✓ Copiar & Rodar
import flet as ft def main(page: ft.Page): page.title = "Placar de Jogo — Comparando 3 Filas (ft.Row)" pontos = ft.Text("10", size=44, weight="bold", color="cyan") # Funções para alterar os pontos do placar: def somar_5(e): pontos.value = str(int(pontos.value) + 5) page.update() def tirar_5(e): pontos.value = str(int(pontos.value) - 5) page.update() def zerar_placar(e): pontos.value = "0" page.update() # ROW 1: SPACE_BETWEEN (Cabeçalho com um texto em cada ponta da janela) linha_topo = ft.Row( [ft.Text("🎮 JOGADOR 1", weight="bold"), ft.Text("🏆 FASE 01", color="yellow")], alignment=ft.MainAxisAlignment.SPACE_BETWEEN # Um na esquerda, outro na direita! ) # ROW 2: CENTER (Placar centralizado bem no meio da tela) linha_placar = ft.Row( [ft.Text("Pontos:", size=22), pontos], alignment=ft.MainAxisAlignment.CENTER # Tudo juntinho no centro! ) # ROW 3: START (Botões alinhados no começo/esquerda com spacing=12) linha_botoes = ft.Row( [ ft.Button("➕ Ganhar 5", on_click=somar_5), ft.Button("➖ Perder 5", on_click=tirar_5), ft.Button("🔄 Zerar", on_click=zerar_placar) ], spacing=12, alignment=ft.MainAxisAlignment.CENTER ) # Empilhamos as 3 Rows dentro de uma Column vertical: painel = ft.Column([linha_topo, linha_placar, linha_botoes], spacing=25) page.add(painel) ft.run(main)
↔️
SPACE_BETWEEN na 1ª Linha (linha_topo):Veja como "🎮 JOGADOR 1" fica colado na esquerda e "🏆 FASE 01" vai lá para a ponta direita!
🎯
CENTER na 2ª e 3ª Linhas:Tanto o número do placar quanto os 3 botões ficam centralizados no meio da janela.
🔢
Por que str(int(pontos.value) + 5)?Porque todo .value de ft.Text é texto! Convertemos para int para somar 5 e devolvemos como str.

🎨 Módulo 4 (1/3) • Introdução aos Conceitos

Aparência e Ícones: theme_mode, window, hint_text e prefix_icon

Entenda o que cada um desses 6 comandos faz para transformar uma janela simples em um aplicativo com cara de celular!

1. page.theme_mode & page.bgcolor theme = tema | bgcolor = cor de fundo

ft.ThemeMode.DARK ativa o modo escuro (ou .LIGHT para claro). Já page.bgcolor pinta o fundo da janela com a cor escolhida.

page.theme_mode = ft.ThemeMode.DARK page.bgcolor = "#0f172a" # Fundo azul escuro
2. page.window.width / height & scroll width = largura | height = altura

Define a largura (width=420) e altura (height=700) da janela para imitar um celular. O ft.ScrollMode.AUTO ativa a rolagem da tela!

page.window.width = 420 # Largura de celular page.scroll = ft.ScrollMode.AUTO
3. hint_text="exemplo@email.com" hint_text = texto de dica dentro da caixa

Enquanto o label é o título do campo, o hint_text mostra um exemplo clarinho dentro da caixa vazia que desaparece ao digitar.

ft.TextField(label="Seu E-mail", hint_text="ana@escola.com")
4. prefix_icon & icon=ft.Icons... prefix_icon = ícone no início da caixa

Desenha um ícone oficial da coleção ft.Icons dentro do TextField (com prefix_icon) ou ao lado do texto de um ft.Button (com icon).

ft.TextField(label="Nome", prefix_icon=ft.Icons.PERSON) ft.Button("Salvar", icon=ft.Icons.CHECK)

Cards e Seletores: Container, Dropdown, Slider e Switch

Facilite a vida do usuário com menus prontos, barras de nota de 0 a 10, interruptores e cartões estilizados!

1. ft.Container(content, padding, border_radius) Container = cartão / moldura visual

Cria um cartão colorido ao redor de um texto ou coluna (content=...), com margem interna (padding) e cantos redondos (border_radius).

cartao = ft.Container(content=ft.Text("Resumo"), bgcolor="#1e293b", padding=15, border_radius=12)
2. ft.Dropdown(label, value, options=[...]) Dropdown = menu de escolha

Cria uma lista de opções fechadas usando ft.dropdown.Option("Nome"). A escolha atual fica em menu.value.

menu = ft.Dropdown(label="Área", value="Cantina", options=[ft.dropdown.Option("Cantina"), ft.dropdown.Option("Quadra")])
3. ft.Slider(min=0, max=10, divisions=10) Slider = barra deslizante de nota

Barra para o usuário arrastar e dar uma nota entre min e max. Como devolve decimal, usamos int(barra.value) para pegar o número inteiro.

barra_nota = ft.Slider(min=0, max=10, divisions=10, value=8)
4. ft.Switch(label, value=False) Switch = interruptor (True / False)

Um interruptor de ligar/desligar. Quando está ativado, interruptor.value vale True; quando desligado, vale False.

chave_urgente = ft.Switch(label="É urgente?", value=False)

Reação Instantânea (on_change) com 2 Slider, 2 Switch e 2 Container

Copie e rode este código: basta arrastar qualquer barra ou mexer nos interruptores e o cartão calcula a média na mesma hora, sem botão!

import flet as ft def main(page: ft.Page): page.title = "Painel ao Vivo — Testando on_change e Containers" page.theme_mode = ft.ThemeMode.DARK page.bgcolor = "#0f172a" page.window.width = 440 page.window.height = 720 page.scroll = ft.ScrollMode.AUTO # Duas barras Slider diferentes (Sabor e Atendimento): slider_sabor = ft.Slider(min=0, max=10, divisions=10, value=8, label="Sabor: {value}") slider_atendimento = ft.Slider(min=0, max=10, divisions=10, value=10, label="Atendimento: {value}") # Dois interruptores Switch diferentes: switch_recomenda = ft.Switch(label="👍 Eu recomendo este lanche", value=True) switch_anonimo = ft.Switch(label="🕵️ Enviar avaliação como Anônimo", value=False) # CONTAINER 1: Cartão que agrupa as barras e interruptores cartao_controles = ft.Container( content=ft.Column([ ft.Text("🍔 1. Nota para o Sabor (0 a 10):"), slider_sabor, ft.Text("🤝 2. Nota para o Atendimento (0 a 10):"), slider_atendimento, switch_recomenda, switch_anonimo ], spacing=6), bgcolor="#1e293b", padding=16, border_radius=14 ) # CONTAINER 2: Cartão de resultado com borda colorida texto_painel = ft.Text("Arraste as barras acima para ver a média ao vivo!", size=16, weight="bold") cartao_resultado = ft.Container( content=texto_painel, bgcolor="#042f2e", # Fundo verde escuro padding=16, border_radius=14, border=ft.Border.all(2, "#10b981") # Borda verde de 2 pixels ) # Função que roda SOZINHA sempre que qualquer Slider ou Switch muda (on_change): def atualizar_ao_vivo(e): nota1 = int(slider_sabor.value) nota2 = int(slider_atendimento.value) media = (nota1 + nota2) / 2 autor = "Anônimo 🕵️" if switch_anonimo.value else "Aluno Identificado 🧑‍🎓" recomendacao = "👍 Recomenda" if switch_recomenda.value else "👎 Não recomenda" texto_painel.value = f"📊 Média Final: {media:.1f}/10\n👤 Autor: {autor} | {recomendacao}" page.update() # Conectamos o evento on_change nos 4 controles: slider_sabor.on_change = atualizar_ao_vivo slider_atendimento.on_change = atualizar_ao_vivo switch_recomenda.on_change = atualizar_ao_vivo switch_anonimo.on_change = atualizar_ao_vivo page.add(ft.Text("⚡ Avaliação em Tempo Real", size=22, weight="bold"), cartao_controles, cartao_resultado) ft.run(main)

Adicionando Cartões (Container) na Lista, Limpando (.clear()) e Blindando com try/except

Copie e teste este Controle de Gastos: ele valida números com try/except, adiciona cartões coloridos na lista e tem botão de limpar tudo!

🐍 exemplo_06_repeticao.py ✓ Copiar & Rodar
import flet as ft def main(page: ft.Page): page.title = "Controle de Gastos — Cards na Lista e Clear" page.theme_mode = ft.ThemeMode.DARK page.bgcolor = "#0f172a" page.window.width = 440 page.window.height = 740 page.scroll = ft.ScrollMode.AUTO lista_de_gastos = [] # Lista Python que guarda os valores numéricos titulo = ft.Text("💰 Meu Controle de Gastos", size=22, weight="bold", color="cyan") campo_descricao = ft.TextField(label="O que você comprou?", hint_text="Ex: Lanche na cantina", prefix_icon=ft.Icons.SHOPPING_BAG) campo_valor = ft.TextField(label="Valor em R$ (apenas números)", hint_text="Ex: 15.50", prefix_icon=ft.Icons.ATTACH_MONEY) aviso = ft.Text("Total gasto: R$ 0.00", size=18, weight="bold", color="yellow") coluna_cartoes_gastos = ft.Column(spacing=10) # FUNÇÃO 1: Valida com try/except e adiciona um Cartão (Container) na coluna visual def adicionar_gasto(e): if campo_descricao.value.strip() == "": aviso.value = "⚠️ Digite a descrição do gasto!" aviso.color = "orange" page.update() return try: # Tenta converter o texto digitado para número decimal (float): preco_convertido = float(campo_valor.value.replace(",", ".")) lista_de_gastos.append(preco_convertido) # Criamos um cartão visual (Container) para este gasto: cartao_novo_gasto = ft.Container( content=ft.Text(f"🛍️ {campo_descricao.value} — R$ {preco_convertido:.2f}", size=15), bgcolor="#1e293b", padding=12, border_radius=10 ) # Adicionamos o cartão inteiro dentro da coluna visual: coluna_cartoes_gastos.controls.append(cartao_novo_gasto) soma_total = sum(lista_de_gastos) aviso.value = f"✅ Salvo! Total gasto ({len(lista_de_gastos)} itens): R$ {soma_total:.2f}" aviso.color = "green" campo_descricao.value = "" campo_valor.value = "" except ValueError: # Se o aluno digitar letras no preço, não trava o app e mostra aviso: aviso.value = "🚨 Erro: digite apenas números no campo de Valor (ex: 12.50)!" aviso.color = "red" page.update() # FUNÇÃO 2: Apaga todos os itens da memória e da coluna visual com .clear() def limpar_historico(e): lista_de_gastos.clear() coluna_cartoes_gastos.controls.clear() aviso.value = "🧹 Histórico apagado! Total gasto: R$ 0.00" aviso.color = "cyan" page.update() linha_botoes = ft.Row([ ft.Button("Adicionar Gasto", icon=ft.Icons.ADD, bgcolor="#10b981", color="white", on_click=adicionar_gasto), ft.Button("Limpar Lista", icon=ft.Icons.DELETE_FOREVER, bgcolor="#ef4444", color="white", on_click=limpar_historico) ], alignment=ft.MainAxisAlignment.CENTER) page.add(ft.Column([titulo, campo_descricao, campo_valor, linha_botoes, aviso, coluna_cartoes_gastos], spacing=12)) ft.run(main)
