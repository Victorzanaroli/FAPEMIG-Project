🛠️ Passo 0 • Preparando o Ambiente

Como Instalar e Rodar o Flet no Computador

O Flet é uma biblioteca externa do Python que cria janelas gráficas. Instalamos uma única vez no terminal!

💻 1. Instalando pelo Terminal do VS Code
# Abra o terminal (Ctrl + ') e digite: pip install flet # Se aparecer erro no comando pip, use: python -m pip install flet

Depois de instalar, crie um arquivo normal com final .py (ex: meu_app.py) e clique em ▶ Run para abrir a janela!

1️⃣
Uma janela de verdade vai abrirEm vez de responder no terminal preto, o Python abre uma janela própria do seu aplicativo.
2️⃣
Para atualizar, feche a janela e rode de novoSempre salve com Ctrl + S antes de clicar em ▶ para ver suas alterações.

🚨 Regra de Ouro: Nunca salve seu arquivo com o nome flet.py! Se fizer isso, o Python confunde seu arquivo com a biblioteca oficial.

Adeus Tela Preta! O Esqueleto de Todo App Flet

Com import flet as ft, a função main(page: ft.Page) vira a janela do nosso aplicativo!

⌨️ Esqueleto Mínimo — meu_primeiro_app.py
import flet as ft def main(page: ft.Page): page.title = "Meu Primeiro App!" # Criamos um texto visual e colocamos na página: titulo = ft.Text("🚀 Olá, Mundo Visual!", size=28) page.add(titulo) ft.app(target=main)
🪟
page: ft.Page → A Janela em BrancoÉ o quadro onde configuramos o título (page.title), o tema e adicionamos os elementos visuais.
➕
page.add(...) → Coloca na TelaSe você criar uma variável com ft.Text(...) mas não colocar no page.add(), ela não aparece na janela!
▶️
ft.app(target=main) → Liga o MotorFica sempre na última linha (sem espaços antes) para iniciar o aplicativo.

🖱️ Tópico 2 • Eventos & Layouts — Explicação (1/2)

Dando Vida ao Botão: on_click e page.update()

Quando o usuário clica no botão, uma função def lê o .value, altera a tela e chama page.update()!

⚡ Como conectar o clique do botão:
nome_input = ft.TextField(label="Qual é o seu nome?") resposta = ft.Text("", size=20, color="cyan") # 1. Função que roda quando o botão é clicado: def saudar(e): resposta.value = f"🎉 Olá, {nome_input.value}!" page.update() # OBRIGATÓRIO para atualizar a tela! # 2. Passamos o nome da função SEM parênteses no on_click: btn = ft.ElevatedButton("Dizer Olá", on_click=saudar) page.add(nome_input, btn, resposta)

🚨 As 3 Regras de Ouro dos Eventos:

1. Parâmetro (e): Toda função ligada a um botão recebe o evento e: def saudar(e):.

2. Chamar page.update(): Se mudar um .value e esquecer o page.update(), a tela continua igualzinha!

3. Sem parênteses no on_click: Escreva on_click=saudar (e nunca on_click=saudar()).

🖱️ Tópico 2 • Eventos & Layouts — Explicação (2/2)

Organizando a Tela: ft.Column (Vertical) vs ft.Row (Horizontal)

Use Column para empilhar um abaixo do outro e Row para colocar elementos lado a lado!

⬇️ ft.Column([...]) → Empilha na Vertical

coluna = ft.Column([ ft.Text("Título em cima"), ft.TextField(label="Campo no meio"), ft.ElevatedButton("Botão embaixo") ], spacing=15)

💡 O parâmetro spacing=15 controla a distância em pixels entre um item e outro.

➡️ ft.Row([...]) → Alinha Lado a Lado

linha_botoes = ft.Row([ ft.ElevatedButton("➕ Somar"), ft.ElevatedButton("➖ Subtrair"), ft.ElevatedButton("🧹 Limpar") ], alignment=ft.MainAxisAlignment.CENTER)

💡 Você pode colocar um ft.Row dentro de um ft.Column para montar qualquer tela!

Interruptores e Ações Rápidas: Switch, Checkbox e IconButton

Controles perfeitos para opções True / False, reação instantânea com on_change e botões compactos!

🔘 ft.Switch e ft.Checkbox (True ou False)

urgente = ft.Switch(label="🔥 Prioridade Urgente", value=False) anonimo = ft.Checkbox(label="Enviar avaliação anônima", value=False) # O .value deles é sempre um booleano (True ou False)! if urgente.value == True: texto.value = "🚨 Marcado como URGENTE!"

🗑️ ft.IconButton e Evento on_change

# Botão redondo só com ícone (ótimo para limpar lista): btn_limpar = ft.IconButton( icon=ft.Icons.DELETE_FOREVER, icon_color="red", tooltip="Limpar tudo", on_click=apagar_lista )

💡 Enquanto botões usam on_click, controles como Dropdown, Slider e Switch também aceitam on_change=funcao para reagir na mesma hora!

Arquitetura Completa: App de Feedback & Avaliação

Veja como E-mail, Categoria (Dropdown), Avaliação (Slider), Blindagem e Lista funcionam juntos!

⌨️ projeto_final_exemplo.py
import flet as ft def main(page: ft.Page): page.title = "Conecta Escola — Feedback" page.theme_mode = ft.ThemeMode.DARK page.window.width = 430 page.scroll = ft.ScrollMode.AUTO banco_dados = [] email = ft.TextField(label="Seu E-mail", prefix_icon=ft.Icons.EMAIL) area = ft.Dropdown(label="Área", value="Ensino", options=[ ft.dropdown.Option("Ensino"), ft.dropdown.Option("Estrutura")]) nota = ft.Slider(min=0, max=10, divisions=10, value=8, label="Nota: {value}") urgente = ft.Switch(label="🔥 Demanda Urgente?", value=False) aviso = ft.Text("", weight="bold") historico = ft.Column() def salvar_avaliacao(e): if "@" not in email.value: aviso.value = "⚠️ Informe um e-mail válido com @!" aviso.color = "red" else: registro = {"email": email.value, "area": area.value, "nota": int(nota.value)} banco_dados.append(registro) tag = "🚨" if urgente.value else "✅" historico.controls.append(ft.Text( f"{tag} [{registro['area']}] {registro['email']} — Nota {registro['nota']}/10")) aviso.value = f"🎉 Salvo! Total de avaliações: {len(banco_dados)}" aviso.color = "green" email.value = "" page.update() page.add(ft.Text("🌟 Central de Avaliação", size=22, weight="bold"), email, area, ft.Text("Sua Nota (0 a 10):"), nota, urgente, ft.ElevatedButton("Enviar Avaliação", icon=ft.Icons.SEND, on_click=salvar_avaliacao), aviso, ft.Text("📋 Histórico:", weight="bold"), historico) ft.app(target=main)
✉️
1. Entrada Identificada e BlindadaO campo email exige "@" antes de aceitar o envio, exibindo feedback colorido em aviso.
🎛️
2. Seletores e Nota de AvaliaçãoCombina Dropdown (setor), Slider (nota 0 a 10) e Switch (prioridade) sem risco de erro numérico.
🗂️
3. Lista de Dicionários + Lista VisualGuarda cada cadastro em banco_dados (Aula 04) e adiciona na tela com historico.controls.append(...)!
