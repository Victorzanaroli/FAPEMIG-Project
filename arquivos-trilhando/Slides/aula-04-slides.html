🧩 Tópico 1 • Funções — Explicação (1/2)

Por que criar Funções? O Comando def

Regra DRY (Don't Repeat Yourself): em vez de repetir o mesmo bloco 10 vezes, crie uma receita e chame pelo nome!

😫 Sem Função (Código repetido e difícil de mudar)

print("====================") print("🎮 BEM-VINDO AO JOGO") print("====================") # Se precisar mostrar 5 vezes, terá que copiar tudo!

✨ Com Função def (Definir 1x, Chamar sempre!)

# 1. DEFINIR (ensina a receita ao Python): def mostrar_painel(): print("====================") print("🎮 BEM-VINDO AO JOGO") print("====================") # 2. CHAMAR (coloca a função em ação!): mostrar_painel() mostrar_painel()
⚠️ Atenção: Só escrever def mostrar_painel(): não imprime nada na tela! A função só roda quando chamamos mostrar_painel() com parênteses embaixo!
🧩 Tópico 1 • Funções — Explicação (2/2)

Passando Ingredientes: Parâmetros e Valores Padrão

Parâmetros ficam nos parênteses ( ) e também podem ter um valor padrão caso o usuário não informe!

1️⃣ Função com 1 ou mais Parâmetros

def apresentar_heroi(nome, nivel): print(f"🛡️ Herói: {nome} | Nível: {nivel}") # Cada chamada envia valores diferentes na mesma ordem: apresentar_heroi("Zelda", 15) apresentar_heroi("Link", 20)

2️⃣ Parâmetro com Valor Padrão (vida=100)

def criar_jogador(nome, vida=100): print(f"🎮 {nome} entrou com ❤️ {vida} de vida!") # Se não passar a vida, assume 100 automaticamente: criar_jogador("Ana") # → ❤️ 100 de vida! criar_jogador("Boss", 500) # → ❤️ 500 de vida!

💡 Parâmetros com valor padrão (=100) evitam TypeError quando um argumento é opcional!

🎁 Tópico 2 • Retorno (return) — Explicação (1/2)

A Diferença entre print() e return

O print() apenas mostra na tela e esquece; o return entrega o valor para guardarmos em uma variável!

📺 Apenas print() (Não devolve o valor)

def somar_sem_return(a, b): print(a + b) # Mostra 8 na tela, mas NÃO entrega para a variável! resultado = somar_sem_return(5, 3) print(resultado) # → Imprime None (Vazio!)

🎁 Com return (Devolve o resultado real!)

def somar(a, b): return a + b # Agora a variável 'total' recebe o número 8! total = somar(5, 3) print(f"O dobro da soma é: {total * 2}") # → 16!
🎁 Tópico 2 • Retorno & Escopo — Explicação (2/2)

Escopo Local: O que nasce na função, fica na função!

Variáveis criadas dentro do def são invisíveis fora dele — por isso usamos o return para tirar o resultado de lá!

🚨 O Erro Clássico: NameError

def calcular_bonus(pontos): bonus = pontos * 2 # 'bonus' nasceu aqui dentro! return bonus # ERRADO: tentar imprimir 'bonus' direto fora da função # print(bonus) → 💥 NameError: 'bonus' is not defined! # CERTO: guardar o retorno da função em uma variável! meu_premio = calcular_bonus(50) print(f"Prêmio final: {meu_premio}") # → 100!

🧮 Exemplo Prático: Calculadora de Média

def calcular_media(n1, n2): media = (n1 + n2) / 2 return media nota_final = calcular_media(8.0, 9.0) if nota_final >= 7.0: print(f"🎉 Aprovado com média {nota_final}!") else: print(f"📚 Média {nota_final}: Estude mais!")

🗂️ Tópico 3 • Dicionários — Explicação Básica (1/3)

Lista vs Dicionário: O Poder do {chave: valor}

Na lista buscamos pelo número da posição [0]; no Dicionário buscamos pelo nome da etiqueta (chave)!

🤔 Com Lista (O que significa cada número?)

heroi_lista = ["Link", 100, 50, "Espada"] # O que é 100? É a vida, o nível ou o ouro? print(heroi_lista[1])

🗂️ Com Dicionário { } (Tudo Etiquetado!)

heroi = { "nome": "Link", "vida": 100, "ouro": 50, "arma": "Espada" } print(heroi["nome"]) # → Link print(heroi["vida"]) # → 100
📌 Anatomia do par "chave": valor: A chave (à esquerda dos dois-pontos :) é a etiqueta de busca, e o valor (à direita) pode ser texto, número, booleano ou até uma lista!
🗂️ Tópico 3 • Dicionários — Explicação Básica (2/3)

Alterando Valores, Criando Chaves e Proteção com .get()

Dicionários NÃO usam .append()! Basta atribuir dicionario["nova_chave"] = valor

✏️ Atualizando 1 Chave ou Criando Nova

pet = {"nome": "Rex", "fome": 50} # 1. Se a chave JÁ EXISTE, substitui o valor: pet["fome"] = 10 # 2. Se a chave NÃO EXISTE, cria na hora: pet["brinquedo"] = "Bolinha" print(pet) # {'nome': 'Rex', 'fome': 10, 'brinquedo': 'Bolinha'}

🛡️ Evitando o KeyError com .get()

# Se a chave não existir, colchetes dão erro: # print(pet["cor"]) → 💥 KeyError: 'cor' # Com .get(), se não existir, devolve o valor padrão: print(pet.get("cor", "Cor não cadastrada"))

💡 Use dicionario.get("chave", "padrão") sempre que não tiver certeza se a chave já foi criada!

🗂️ Tópico 3 • Dicionários — Explicação Básica (3/3)

Comandos Poderosos: .update(), .pop(), del e in

Como atualizar várias chaves de uma vez, apagar etiquetas com segurança e verificar se uma chave existe!

⚡
dict.update({...}) → Atualiza/Adiciona em LoteModifica várias chaves existentes e cria chaves novas em um único comando!
🗑️
dict.pop("chave", padrao) → Remove e DevolveApaga a chave do dicionário e entrega o valor que estava guardado nela.
✂️
del dict["chave"] → Apaga DiretoRemove o par chave-valor na hora (cuidado: dá KeyError se não existir).
🔍
"chave" in dict & len(dict) → Checa e ContaTesta com if "vip" in conta: se a etiqueta existe e conta pares com len().

💻 Veja os 4 comandos em ação no VS Code:

conta = {"usuario": "Nina", "pontos": 100, "temp": "abc"} # 1. .update() atualiza 'pontos' e cria 'nivel' e 'vip' de uma vez! conta.update({"pontos": 250, "nivel": 5, "vip": True}) # 2. .pop() remove a chave 'temp' com segurança: removido = conta.pop("temp", "Não tinha") # 3. Verificando com 'in' e contando com len(): if "vip" in conta: print(f"🌟 VIP ativo! Total de chaves: {len(conta)}") print(conta)

🔁 Tópico 4 • Dicionários e Laços — Explicação (1/2)

Percorrendo Dicionários: .keys(), .values() e .items()

Como usar o laço for para ler todas as etiquetas e todos os valores de um dicionário automaticamente!

🔑 .keys() (Só Chaves) vs 📊 .values() (Só Valores)

notas = {"Matemática": 9.5, "Python": 10.0, "Física": 8.0} # 1. Ver apenas as matérias (chaves): print(list(notas.keys())) # ['Matemática', 'Python', 'Física'] # 2. Somar apenas as notas (valores): soma = 0 for v in notas.values(): soma = soma + v print(f"Soma das notas: {soma}")

🏆 O Campeão: .items() (Chave + Valor juntos!)

# Com .items(), o for entrega a CHAVE e o VALOR ao mesmo tempo! for materia, nota in notas.items(): print(f"📘 {materia} → Nota: {nota}") # Saída no terminal: # 📘 Matemática → Nota: 9.5 # 📘 Python → Nota: 10.0 # 📘 Física → Nota: 8.0

💡 Dica de Ouro: Em for k, v in d.items():, a 1ª variável sempre recebe a chave e a 2ª recebe o valor!
