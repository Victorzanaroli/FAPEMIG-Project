Instalando o Flet e testando se está tudo certo

O Flet é uma biblioteca: um pacote de código pronto que alguém criou e que a gente instala para usar. Faça isso só uma vez.

Menu Terminal → Novo Terminal (ou Ctrl + '). Digite e aperte Enter:

Se aparecer "pip não é reconhecido", use:

2️⃣ Teste se instalou

python -c "import flet; print('Flet OK!')"

Apareceu Flet OK!? Perfeito, pode seguir! 🎉

Salve o arquivo (ex.: ola_flet.py) e clique no botão ▶️ do VS Code ou digite no terminal:

python ola_flet.py

Uma janela nova vai abrir. Para fechar o app, feche a janela (ou Ctrl+C no terminal).

📖 Tópico 1 • Flet Básico — Explicação (1/3)

Adeus tela preta! O que é o Flet e como ele pensa?

Até agora nossos programas conversavam pelo terminal. Com o Flet, eles ganham uma janela igual à de qualquer aplicativo.

🧱 Pense assim: um mural de cortiça
A página (page) é um mural em branco. Cada elemento visual — um texto, uma caixa de digitação, um botão — é um papelzinho que você cria e depois prende no mural com page.add(). Se você criar o papel mas não prender, ninguém vê!

No Flet, esses "papeizinhos" se chamam controles (ou widgets). Todo controle começa com ft. e uma letra maiúscula: ft.Text, ft.TextField, ft.ElevatedButton...

E tudo que você já aprendeu continua valendo: variáveis, if/else, listas, funções. O Flet só muda onde as coisas aparecem.

Os 3 blocos de LEGO: Text, TextField e ElevatedButton

Veja a "tradução" do que fazíamos no terminal para os controles visuais do Flet.

O que queremos fazerNo Terminal (antigo)No Flet (novo!)Como ler / mudar o valor?
📝 Mostrar texto na tela print("Olá!") msg = ft.Text("Olá!", size=20) msg.value = "Novo texto"
⌨️ Pedir digitação do usuário nome = input("Nome: ") campo = ft.TextField(label="Nome") campo.value (guarda o que foi digitado)
🖱️ Executar uma ação Apertar Enter btn = ft.ElevatedButton("Enviar", on_click=acao) Chama a função def acao(e): no clique
🔑 A palavra mágica: .value
Pense no .value como o "conteúdo da caixinha". Em um ft.Text, é o texto que aparece. Em um ft.TextField, é o que a pessoa digitou. Ler: campo.value. Mudar: msg.value = "...".

🎨 Opções extras que você pode testar

ft.TextField(label="Idade", hint_text="Ex.: 15", width=200)
ft.ElevatedButton("Salvar", width=200)

⚠️ TextField.value é sempre texto (str), mesmo se digitarem números — igual ao input(). Para fazer contas, use int() ou float().

📖 Tópico 2 • Eventos & Layouts — Explicação (1/4)

Dando vida ao botão: o que é um evento?

No terminal, o programa rodava de cima para baixo e acabava. Num app, o programa fica esperando o usuário fazer alguma coisa.

🔔 Pense assim: a campainha de casa
A campainha fica quietinha até alguém apertar. Quando apertam, ela toca. No Flet, o botão é a campainha, o clique é o evento, e a função que você liga a ele é o "som" que toca. A ligação é feita com on_click=nome_da_funcao.

Evento = qualquer coisa que o usuário faz: clicar, digitar, escolher uma opção, arrastar uma barra... Cada controle avisa o Flet quando um evento acontece.

A função ligada ao evento recebe um parâmetro chamado e (de evento): def saudar(e):. Por enquanto, basta saber que ele precisa estar ali, mesmo que você não use.

🔄 O ciclo que acontece a CADA clique:

1️⃣ 👆 O usuário clica no botão.
2️⃣ 📞 O Flet chama a função que está no on_click.
3️⃣ ✏️ A função lê valores (campo.value) e muda controles (msg.value = ...).
4️⃣ 🔄 A função chama page.update() → o Flet redesenha a tela com as mudanças.

⚠️ O passo 4 é o mais esquecido! Sem page.update(), a mudança acontece "por dentro", mas a tela continua igual.

🚨 Tópico 2 • Eventos & Layouts — Explicação (3/4)

As 3 pegadinhas que mais travam quem está começando

Se o seu botão "não funciona", 90% das vezes é uma destas. Compare o errado com o certo.

❌ 1. Esqueceu o page.update()

def saudar(e): resposta.value = "Olá!" # faltou atualizar!

Sintoma: clica e nada acontece, nenhum erro aparece.

✅ Certo

def saudar(e): resposta.value = "Olá!" page.update()

❌ 2. Parênteses no on_click

ft.ElevatedButton("Oi", on_click=saudar())

Sintoma: a função roda sozinha ao abrir o app (ou dá erro), e o clique não faz nada. Com () você executa a função na hora, em vez de entregá-la ao botão.

✅ Certo

ft.ElevatedButton("Oi", on_click=saudar)

❌ 3. Esqueceu o (e)

def saudar(): resposta.value = "Olá!" page.update()

Sintoma: ao clicar, aparece no terminal TypeError: saudar() takes 0 positional arguments but 1 was given. O Flet sempre envia o evento para a função.

✅ Certo

def saudar(e): ...
📖 Tópico 2 • Eventos & Layouts — Explicação (4/4)

Organizando a tela: ft.Column (vertical) e ft.Row (horizontal)

Por padrão, o page.add() empilha tudo um embaixo do outro. Para controlar a arrumação, usamos "caixas organizadoras".

📦 Pense assim: prateleiras e gavetas
ft.Column é uma pilha de gavetas (um em cima do outro). ft.Row é uma prateleira (um do lado do outro). Os dois recebem uma lista [ ] de controles — sim, a mesma lista da Aula 03! E dá para colocar uma Row dentro de uma Column.

⬇️ ft.Column — empilha

coluna = ft.Column([ ft.Text("Título"), ft.TextField(label="Campo"), ft.ElevatedButton("Botão") ], spacing=15) page.add(coluna)

⚡ Tópico 2 • Prática 2 — Mão na Massa! ⏱️ 20 min

Contador de Cliques Gamer 🎮

Objetivo: um placar grande e dois botões lado a lado — +1 Ponto soma 1 e Zerar volta para 0.

🪜 Passo a passo

  1. Crie pratica2_contador.py com o esqueleto.
  2. Crie o placar: placar = ft.Text("0", size=45, weight="bold").
  3. Crie a função def ganhar_ponto(e):. Dentro dela:
    a) pegue o texto do placar e transforme em número: int(placar.value);
    b) some 1;
    c) transforme de volta em texto com str(...) e guarde em placar.value;
    d) chame page.update().
  4. Crie a função def zerar(e): que coloca "0" no placar e atualiza.
  5. Crie os 2 botões, cada um com seu on_click, dentro de um ft.Row([...]).
  6. Adicione na página o placar e a Row.
💡 Dica — por que preciso de int() e str()?
O .value de um ft.Text é texto. "0" + 1 dá erro (não dá para somar texto com número). Então fazemos: texto → número (int) → soma → número → texto (str).
Em uma linha só: placar.value = str(int(placar.value) + 1)

🔄 Zerar

✅ Deu certo se...

  • ☑️ Cada clique em "+1 Ponto" aumenta o número
  • ☑️ "Zerar" volta para 0
  • ☑️ Os botões estão lado a lado (não um embaixo do outro)

🏅 Desafio extra: crie um botão "−1 Ponto" que não deixa o placar ficar negativo (use if!).

🔓 Ver solução completa
import flet as ft def main(page: ft.Page): page.title = "Contador Gamer" placar = ft.Text("0", size=45, weight="bold") def ganhar_ponto(e): placar.value = str(int(placar.value) + 1) page.update() def zerar(e): placar.value = "0" page.update() page.add( placar, ft.Row([ ft.ElevatedButton("⚡ +1 Ponto", on_click=ganhar_ponto), ft.ElevatedButton("🔄 Zerar", on_click=zerar) ]) ) ft.app(target=main)

🛡️ Tópico 3 • Flet Avançado — Explicação (3/3)

Blindagem visual: avisando o usuário em vez de travar

Lembra do try/except da Aula 03? No Flet ele é ainda mais importante: em vez de um erro vermelho no terminal, mostramos um aviso amigável na tela.

campo_num = ft.TextField(label="Digite um número") aviso = ft.Text("") def calcular(e): if campo_num.value.strip() == "": # ① campo vazio? aviso.value = "⚠️ Preencha o campo!" aviso.color = "orange" else: try: # ② tenta converter valor = float(campo_num.value) aviso.value = f"✅ O dobro é {valor * 2}" aviso.color = "green" except ValueError: # ③ deu errado? aviso.value = "❌ Digite apenas números!" aviso.color = "red" page.update() # ④
①
.strip() remove espaços das pontas. Se sobrou "", a pessoa não digitou nada (ou só espaços).
②
O try tenta transformar o texto em número. Se der certo, mostra o resultado em verde.
③
Se a pessoa digitou "abc", o float() falha e o Python pula para o except, que mostra o aviso em vermelho. O app não trava!
④
Um único page.update() no final vale para todos os caminhos.

O que o usuário vê em cada caso:

digitou "" → ⚠️ Preencha o campo!
digitou "abc" → ❌ Digite apenas números!
digitou "7.5" → ✅ O dobro é 15.0

💡 Use ponto, não vírgula: 7.5 funciona, 7,5 cai no except.

⚡ on_click × on_change — qual usar?

on_click → botões (ElevatedButton, IconButton): roda quando clica.
on_change → Dropdown, Slider, Switch, Checkbox, TextField: roda na hora que o valor muda, sem precisar de botão. Ex.: ft.Slider(min=0, max=10, on_change=atualizar_nota).

Várias telas no mesmo app com ft.NavigationBar

Aquela barra de abas embaixo, igual a do Instagram ou WhatsApp. O segredo: todas as telas existem ao mesmo tempo, mas só uma fica visível.

📺 Pense assim: canais de TV
Todos os canais estão sendo transmitidos, mas a TV mostra só um. Trocar de aba = trocar de canal: escondemos uma tela (visible = False) e mostramos outra (visible = True). Vantagem: o que foi digitado em uma aba não se perde ao trocar!
import flet as ft def main(page: ft.Page): page.title = "App com Abas" tela_inicio = ft.Column([ft.Text("🏠 Aba Início", size=24)], visible=True) # ① tela_sobre = ft.Column([ft.Text("ℹ️ Sobre a Dupla", size=24)], visible=False) def mudar_aba(e): idx = e.control.selected_index # ② tela_inicio.visible = (idx == 0) # ③ tela_sobre.visible = (idx == 1) page.update() page.navigation_bar = ft.NavigationBar( # ④ on_change=mudar_aba, destinations=[ ft.NavigationBarDestination(icon=ft.Icons.HOME, label="Início"), ft.NavigationBarDestination(icon=ft.Icons.INFO, label="Sobre") ] ) page.add(tela_inicio, tela_sobre) # ⑤ ft.app(target=main)
①
Cada tela é uma Column. A primeira começa visível (True), a outra escondida (False).
②
Aqui finalmente usamos o e! e.control é quem disparou o evento (a barra) e selected_index é o número da aba clicada. Começa no 0, igual às posições de lista!
③
(idx == 0) vira True ou False. Se clicou na aba 0, o Início aparece; senão, some.
④
A barra não vai no page.add: ela tem um lugar próprio, page.navigation_bar, e fica sempre fixa embaixo.
⑤
As duas telas são adicionadas — mas só a visível aparece.

Desafio Mestre: "Controle Inteligente" com menu, validação e lista

Objetivo: juntar tudo da aula num app só. O usuário descreve um item, escolhe o tipo, digita um valor e o item entra numa lista na tela — com proteção contra erros.

🎯 Checklist do seu app

  1. Janela: page.title, ThemeMode.DARK e page.scroll = ft.ScrollMode.AUTO.
  2. Entradas: um TextField "Descrição", um Dropdown "Tipo" (Meta / Gasto) e um TextField "Valor".
  3. Avisos: um ft.Text("") chamado aviso.
  4. Lista: historico = ft.Column() vazia.
  5. Função salvar(e): se a descrição estiver vazia → aviso vermelho. Senão, try: converta o valor com float() e dê historico.controls.append(ft.Text(...)); except ValueError: aviso vermelho "Digite um número válido!".
  6. Botão "Adicionar" com ícone ligado a salvar.
💡 Dica — por onde começar?
Faça em partes e rode a cada parte: 1) só a janela e os campos aparecendo; 2) o botão mostrando qualquer texto no aviso; 3) a validação; 4) a lista. Programadores profissionais trabalham assim — passinho por passinho!
