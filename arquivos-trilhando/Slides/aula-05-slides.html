Como Instalar e Rodar o Flet no Computador

O Flet é uma biblioteca externa do Python que cria janelas gráficas. Instalamos uma única vez no terminal!

💻 1. Instalando pelo Terminal do VS Code
python -m pip install flet

Depois de instalar, crie um arquivo normal com final .py (ex: meu_app.py), cole qualquer código desta aula e clique em ▶ Run!

1️⃣
Uma janela de verdade vai abrirEm vez de responder no terminal preto, o Python abre uma janela própria do seu aplicativo.
2️⃣
Para testar o próximo código, feche a janela e rode de novoSempre salve com Ctrl + S antes de clicar em ▶ para ver suas alterações.

🚨 Regra de Ouro: Nunca salve seu arquivo com o nome flet.py! Se fizer isso, o Python confunde seu arquivo com a biblioteca oficial.

📱 Tópico 1 • Primeiros Passos — Explicação (1/3)

Conhecendo: .title, ft.Text, page.add() e ft.run()

Antes de rodarmos o primeiro código, veja o que cada um desses 4 comandos faz para criar uma janela visual!

🪟 1. page.title e ft.Text(...)

# .title muda o nome na barra superior da janela: page.title = "Meu Primeiro App" # ft.Text cria um texto visual (substitui o print): # size = tamanho da letra | color = cor da letra # weight="bold" = espessura da fonte em negrito titulo = ft.Text( "🚀 Olá, Mundo!", size=26, color="cyan", weight="bold" )

➕ 2. page.add(...) e ft.run(main)

# page.add() cola o elemento criado dentro da janela! # (Sem o page.add, o texto fica só na memória e não aparece) page.add(titulo) # ft.run(main) fica sempre na última linha do arquivo: # Ele liga o motor do Flet e abre a janela na tela! ft.run(main)

💡 Resumo: Criamos o texto com ft.Text(), colocamos na tela com page.add() e ligamos o app com ft.run(main)!

Conhecendo: ft.TextField, ft.Button, on_click e page.update()

Comando NovoPara que serve na prática?Exemplo comentado de como usar
ft.TextField(label="...") Cria uma caixa de digitação (substitui o input). O que o usuário digitar fica guardado em .value. campo_nome = ft.TextField(label="Digite seu nome")

Pegando o Código do Tópico 1 e Adicionando TextField, Button e update()

Praticando com 2 TextField, 2 Button e 2 Funções com update()

Copie e teste este Criador de Herói: um botão lê as duas caixas para montar a ficha e o outro limpa tudo!

⌨️ exemplo_02_repeticao.py
import flet as ft def main(page: ft.Page): page.title = "Criador de Herói — Dois Campos e Dois Botões" titulo = ft.Text("🦸 Monte a Ficha do Seu Herói", size=24, weight="bold") # Criamos 2 campos de digitação (TextField) diferentes: campo_heroi = ft.TextField(label="1. Nome do Herói (ex: Tempestade)") campo_poder = ft.TextField(label="2. Superpoder (ex: Controlar Raios)") # Texto onde o resultado vai aparecer: resultado = ft.Text("Preencha os 2 campos acima...", size=18, color="yellow") # FUNÇÃO DO BOTÃO 1: Lê os dois .value e mostra a ficha na tela def mostrar_heroi(e): resultado.value = f"⚡ Herói: {campo_heroi.value} | Poder: {campo_poder.value}" resultado.color = "green" page.update() # Atualiza a tela com a ficha pronta # FUNÇÃO DO BOTÃO 2: Esvazia as caixas colocando "" nos .value def limpar_tudo(e): campo_heroi.value = "" campo_poder.value = "" resultado.value = "🧹 Campos limpos! Lendo vários campos ao mesmo tempo:Em mostrar_heroi(e), juntamos campo_heroi.value e campo_poder.value na mesma frase!
2️⃣
Limpando caixas de texto pelo código:Em limpar_tudo(e), colocar campo_heroi.value = "" e chamar page.update() apaga o texto digitado na hora!

📐 Tópico 3 • Layouts Visuais — Explicação (1/3)

Organizando a Tela: ft.Column, ft.Row e Alinhamentos

Use Column para empilhar na vertical, Row para alinhar lado a lado e entenda os eixos de alinhamento!

⬇️ ft.Column([...]) → Empilha na Vertical

# Empilha os itens de cima para baixo: coluna = ft.Column( [ ft.Text("Título em cima"), ft.TextField(label="Campo no meio"), ft.Button("Botão embaixo") ], spacing=15, # Distância de 15px entre cada item # CrossAxisAlignment.CENTER centraliza a coluna na horizontal: horizontal_alignment=ft.CrossAxisAlignment.CENTER )

➡️ ft.Row([...]) → Alinha Lado a Lado

# Coloca os itens lado a lado na mesma linha horizontal: linha_botoes = ft.Row( [ ft.Button("✅ Criar"), ft.Button("🧹 Limpar") ], spacing=12, # Espaço lateral de 12px entre os botões # MainAxisAlignment.CENTER centraliza a fila no meio da linha: alignment=ft.MainAxisAlignment.CENTER )

💡 Você pode colocar uma ft.Row dentro de uma ft.Column (e clicar em 🔤 Notas & Tradução para ver o guia completo dos alinhamentos)!

🔁 Tópico 3 • Prática com Repetição (3/3) — Vendo a Diferença

Comparando 3 ft.Row com Alinhamentos Diferentes na Mesma Tela

Copie e rode este placar de jogo para ver a diferença visual entre SPACE_BETWEEN, CENTER e START!

⌨️ exemplo_03_repeticao.py
import flet as ft def main(page: ft.Page): page.title = "Placar de Jogo — Comparando 3 Filas (ft.Row)" pontos = ft.Text("10", size=44, weight="bold", color="cyan") def somar_5(e): pontos.value = str(int(pontos.value) + 5) page.update() def tirar_5(e): pontos.value = str(int(pontos.value) - 5) page.update() def zerar_placar(e): pontos.value = "0" page.update() # ROW 1: SPACE_BETWEEN (Coloca um texto na ponta esquerda e outro na ponta direita!) linha_topo = ft.Row( [ft.Text("🎮 JOGADOR 1", weight="bold"), ft.Text("🏆 FASE 01", color="yellow")], alignment=ft.MainAxisAlignment.SPACE_BETWEEN ) # ROW 2: CENTER (Centraliza o rótulo e o número do placar bem no meio da tela) linha_placar = ft.Row( [ft.Text("Pontos:", size=22), pontos], alignment=ft.MainAxisAlignment.CENTER ) # ROW 3: CENTER com 3 botões lado a lado e spacing=12 entre eles linha_botoes = ft.Row( [ ft.Button("➕ Ganhar 5", on_click=somar_5), ft.Button("➖ Perder 5", on_click=tirar_5), ft.Button("🔄 Zerar", on_click=zerar_placar) ], spacing=12, alignment=ft.MainAxisAlignment.CENTER ) # Empilhamos as 3 Rows dentro de uma Column vertical: painel = ft.Column([linha_topo, linha_placar, linha_botoes], spacing=25) page.add(painel) ft.run(main)
↔️
1ª Row (SPACE_BETWEEN):Veja como "🎮 JOGADOR 1" fica na esquerda e "🏆 FASE 01" vai automaticamente para a extrema direita!
🎯
2ª e 3ª Rows (CENTER):Centralizam o número do placar e a barra com os 3 botões no meio da janela.
🔢
Somando números em ft.Text:Convertemos int(pontos.value) + 5 para fazer a conta e usamos str(...) para devolver como texto!

Reação Instantânea (on_change) com 2 Slider, 2 Switch e 2 Container

Copie e rode: basta arrastar qualquer barra ou mexer nos interruptores e o cartão calcula a média na hora, sem botão!

⌨️ exemplo_05_repeticao.py
import flet as ft def main(page: ft.Page): page.title = "Painel ao Vivo — Testando on_change e Containers" page.theme_mode = ft.ThemeMode.DARK page.bgcolor = "#0f172a" page.window.width = 440 page.window.height = 720 page.scroll = ft.ScrollMode.AUTO # Duas barras Slider diferentes (Sabor e Atendimento): slider_sabor = ft.Slider(min=0, max=10, divisions=10, value=8, label="Sabor: {value}") slider_atendimento = ft.Slider(min=0, max=10, divisions=10, value=10, label="Atendimento: {value}") # Dois interruptores Switch diferentes: switch_recomenda = ft.Switch(label="👍 Eu recomendo este lanche", value=True) switch_anonimo = ft.Switch(label="🕵️ Enviar avaliação como Anônimo", value=False) # CONTAINER 1: Cartão que agrupa as barras e interruptores cartao_controles = ft.Container( content=ft.Column([ ft.Text("🍔 1. Nota para o Sabor (0 a 10):"), slider_sabor, ft.Text("🤝 2. Nota para o Atendimento (0 a 10):"), slider_atendimento, switch_recomenda, switch_anonimo ], spacing=6), bgcolor="#1e293b", padding=16, border_radius=14 ) # CONTAINER 2: Cartão de resultado com borda verde de 2 pixels texto_painel = ft.Text("Arraste as barras acima para ver a média ao vivo!", size=16, weight="bold") cartao_resultado = ft.Container( content=texto_painel, bgcolor="#042f2e", padding=16, border_radius=14, border=ft.Border.all(2, "#10b981") ) # Função acionada automaticamente sempre que qualquer Slider ou Switch muda (on_change): def atualizar_ao_vivo(e): nota1 = int(slider_sabor.value) nota2 = int(slider_atendimento.value) media = (nota1 + nota2) / 2 autor = "Anônimo 🕵️" if switch_anonimo.value else "Aluno Identificado 🧑‍🎓" recomendacao = "👍 Recomenda" if switch_recomenda.value else "👎 Não recomenda" texto_painel.value = f"📊 Média Final: {media:.1f}/10\n👤 Autor: {autor} | {recomendacao}" page.update() # Conectamos o evento on_change nos 4 controles: slider_sabor.on_change = atualizar_ao_vivo slider_atendimento.on_change = atualizar_ao_vivo switch_recomenda.on_change = atualizar_ao_vivo switch_anonimo.on_change = atualizar_ao_vivo page.add(ft.Text("⚡ Avaliação em Tempo Real", size=22, weight="bold"), cartao_controles, cartao_resultado) ft.run(main)
⚡
O poder do .on_change:Ao rodar, arraste qualquer barra: a média dentro do cartão verde atualiza na mesma hora sem precisar clicar em nenhum botão!
🃏
Comparando 2 ft.Container:O 1º cartão envolve uma Column inteira com os controles; o 2º cartão destaca o placar de resultado com borda colorida (ft.Border.all).

Adicionando Cartões (Container) na Lista, Limpando (.clear()) e Blindando com try/except

Copie e teste este Controle de Gastos: ele valida números com try/except, adiciona cartões na lista e tem botão para limpar tudo!

⌨️ exemplo_06_repeticao.py
import flet as ft def main(page: ft.Page): page.title = "Controle de Gastos — Cards na Lista e Clear" page.theme_mode = ft.ThemeMode.DARK page.bgcolor = "#0f172a" page.window.width = 440 page.window.height = 740 page.scroll = ft.ScrollMode.AUTO lista_de_gastos = [] # Lista Python que guarda os valores numéricos titulo = ft.Text("💰 Meu Controle de Gastos", size=22, weight="bold", color="cyan") campo_descricao = ft.TextField(label="O que você comprou?", hint_text="Ex: Lanche na cantina", prefix_icon=ft.Icons.SHOPPING_BAG) campo_valor = ft.TextField(label="Valor em R$ (apenas números)", hint_text="Ex: 15.50", prefix_icon=ft.Icons.ATTACH_MONEY) aviso = ft.Text("Total gasto: R$ 0.00", size=18, weight="bold", color="yellow") coluna_cartoes_gastos = ft.Column(spacing=10) # FUNÇÃO 1: Valida com try/except e adiciona um Cartão (Container) na coluna visual def adicionar_gasto(e): if campo_descricao.value.strip() == "": aviso.value = "⚠️ Digite a descrição do gasto!" aviso.color = "orange" page.update() return try: # Tenta converter o valor digitado para número decimal (float): preco_convertido = float(campo_valor.value.replace(",", ".")) lista_de_gastos.append(preco_convertido) # Criamos um cartão visual (Container) para este gasto: cartao_novo_gasto = ft.Container( content=ft.Text(f"🛍️ {campo_descricao.value} — R$ {preco_convertido:.2f}", size=15), bgcolor="#1e293b", padding=12, border_radius=10 ) # Adicionamos o cartão inteiro dentro da coluna visual: coluna_cartoes_gastos.controls.append(cartao_novo_gasto) soma_total = sum(lista_de_gastos) aviso.value = f"✅ Salvo! Total gasto ({len(lista_de_gastos)} itens): R$ {soma_total:.2f}" aviso.color = "green" campo_descricao.value = "" campo_valor.value = "" except ValueError: # Se digitar letras no preço, o app não fecha e mostra aviso amigável: aviso.value = "🚨 Erro: digite apenas números no campo de Valor (ex: 12.50)!" aviso.color = "red" page.update() # FUNÇÃO 2: Apaga todos os itens da memória e da tela com .clear() def limpar_historico(e): lista_de_gastos.clear() coluna_cartoes_gastos.controls.clear() aviso.value = "🧹 Histórico apagado! Total gasto: R$ 0.00" aviso.color = "cyan" page.update() linha_botoes = ft.Row([ ft.Button("Adicionar Gasto", icon=ft.Icons.ADD, bgcolor="#10b981", color="white", on_click=adicionar_gasto), ft.Button("Limpar Lista", icon=ft.Icons.DELETE_FOREVER, bgcolor="#ef4444", color="white", on_click=limpar_historico) ], alignment=ft.MainAxisAlignment.CENTER) page.add(ft.Column([titulo, campo_descricao, campo_valor, linha_botoes, aviso, coluna_cartoes_gastos], spacing=12)) ft.run(main)
🛡️
Teste digitar letras no Valor (ex: "vinte"):O bloco try / except ValueError impede que a janela trave e exibe o aviso vermelho pedindo apenas números!
🧹
Vendo .append() e .clear() juntos:Cada clique em Adicionar Gasto empilha um novo cartão estilizado; clicar em Limpar Lista apaga todos com .controls.clear()!
